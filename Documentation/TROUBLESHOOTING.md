# Troubleshooting Guide

This document lists common issues and their solutions for the system setup.

---

## Ubuntu ISO issue

### Problem: VMware won't boot Ubuntu
**Solution:**
```text
Accidently downloaded intel/amd x64 iso instead of ARM x64
after downloading the correct ISO for the system everything booted correctly
```

## SSH login issue

### Problem: SSH wont let me login as the password was getting declined
**Solution:**
```text
Using the correct username, in my case 'q', instead of "admin" 
```
